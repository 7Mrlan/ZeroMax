# 目标模式启动审查记录

更新时间：2026-10-12（Asia/Shanghai）  
审查基准：`1a608c1`（本轮 Android JSI 注册、target adapter 生命周期关闭和 target artifact ownership preflight 收口后的最新干净提交；后续提交以新的 HEAD 重新审查）
目标分支：`codex/zero-zerox`

## 审查结论

目标模式可以继续执行，但不能把“依赖已安装、Jest 通过、APK 编译成功”当作完成。当前目标仍受四类事实阻断：

1. Android 迁移恢复源码已覆盖 `writing`/`verified` 状态的 reconcile，且 post-copy 状态失败会先关闭 target adapter；仍需要设备上真实用户行 batch、进程被杀后的下一次启动证据，必须证明不会重复复制、覆盖未知库或丢失源库。
2. E2E 和无障碍契约已有稳定 `testID`、Maestro 流程和 selected/expanded/switch state，但尚无真实设备执行记录。
3. API 35 x86_64 模拟器已经提供 fresh v4 JSI 冷启动和空 Zero v3 target activation 证据；代表性 Zero/Zerox fixture 已通过 native writer；大规模迁移仍待验证，尚无迁移中断、E2E/TalkBack、切换帧耗时、列表 jank、内存和数据库复制样本，因此禁止写入性能提升百分比。
4. Android 正式签名材料、iOS Pods/设备验证和 iOS 原生只读/安全存储桥接仍是外部环境或源码收口工作；macOS 不属于本仓库目标平台。

上述阻断不会暂停目标模式。每次继续工作前都读取最新 HEAD、lockfile、测试结果和本记录，重新排序剩余工作。

## 多维度对抗性审查

### 范围与产品

- Zero `d7725cd` 的预算、CSV/JSON、诊断、WCAG 颜色、FlashList、撤销、图表和债务是继承基线，不重复计入新功能。
- Zerox `a21abd6` 只吸收收入、父子分类、中文/英文 key、主题和 AI 的行为契约；旧实现逐项重写到当前 v4 数据域，不原样复制旧网络、逐条写入或旧列表实现。
- `expenses` 与 `incomes` 保持双表，通过 `TransactionRecord` repository 统一查询；导出格式使用 v5，分类复合键包含 `kind + parentName + name`。

### 技术与依赖

目标锁定为：RN `0.87.1`、React `19.3.0`、TypeScript `7.0.2`、Reanimated `4.7.1`、Worklets `0.13.0`、Navigation `7.5.0/7.20.0`、Redux Toolkit `2.13.0`、FlashList `2.3.3`、WatermelonDB `0.28.0`、MMKV `4.3.2`、Zod `4.6.5`。版本来源和 peer/原生风险见 [改造探索与方案](./改造探索与方案.md) 与 `package.json` 的 dependency notes。

不采用旧版本兼容分支。每次升级或原生改动必须同时检查 `pnpm-lock.yaml`、RN peer 范围、Hermes/Fabric 编译和受影响测试；仅改 `package.json` 不算升级完成。

### 数据安全

数据库顺序固定为：native readonly probe → WAL/SHM-aware backup → 隔离 v4 target → 单次写入 → read-back/金额/ID/关系/索引/integrity/reopen → pointer activation。Watermelon `batch()` 返回后不能由 JS 跨数据库回滚；校验失败只能关闭 adapter 后丢弃未激活 target，并在 checkpoint 中保留可解释状态。

任何未知、未来、损坏、锁定、权限不足、孤儿 sidecar、marker 不匹配或 source fingerprint 改变都必须 fail closed。目标恢复不能根据文件大小/时间猜测归属，也不能在未确认 ownership 时 reset。

### 隐私与 AI

AI 默认关闭。API key 只进入平台安全存储，不进入 Redux、Watermelon、导出、日志、错误上报或 bundle；网络只接受 HTTPS/allowlist，具备超时、取消、响应上限和有限重试。解析结果必须通过 Zod；任务、记录和重试使用稳定幂等键，重复执行不得新增第二笔账。

任务状态存于 MMKV、账单写入存于 WatermelonDB，二者不能声称跨存储原子提交。实现采用先完成幂等记录写入，再持久化任务完成标记；进程若在两者之间退出，下一次运行通过稳定记录 ID 跳过已存在记录并补写完成标记。

## 2026-10-12 P0/P4/P6 增量

- `280935d` 将 durable checkpoint 接入 Android coordinator 的 recovery：matched `writing` 在 adapter close 后 discard/rebuild，matched `verified` 通过只读 exact schema/integrity/fingerprint 后 reopen/reuse；同一 attempt 的 verified instance 在同一 JS 进程用 Map 防止第二个 JSI adapter。
- `e2c9fc8` 要求性能报告携带 raw observations 和可复现 metadata，并以候选 P95 相对 Zero 不超过 5% 作为结构性 release block；没有真实 `performance/latest.json` 时不生成或填写数字。
- `114d17f`、`95bfaf2`、`b08c119` 将 E2E/a11y 标识与 Maestro 流程分开提交；当前仅是可执行契约，设备/TalkBack/VoiceOver 仍是外部验收。
- 本轮补齐 active-pointer=target 的同进程 retry 边界：已 adopt 的 v4 `Database` 在普通 retry 中保留，只有显式 `force` 才清除 singleton，避免 activation marker 写入失败后构造第二个 JSI adapter；adoption 单测覆盖该行为。
- 首页 focus 不再无条件清空 keyed month cache；fulfilled 月份直接复用，只有 pull-to-refresh 触发 invalidate/query，避免导航切换闪屏和重复 SQLite 查询。该优化仍需设备 benchmark 验证，不宣称固定性能百分比。
- 交易流水已使用日期 header + `transaction`/`pendingDelete` 的单一 FlashList 数据源，key 为 `kind:id`；卸载时会 flush 待删除记录，避免列表回收或后台切换导致删除复活。该结构改进仍需设备 FPS/jank/RSS 数据验证。
- 首页现在按月并行加载 expenses/incomes，流水按 kind:id 合并；预算和“已花费”仍只统计支出，年份缓存合并两张表，避免收入月份在选择器和首页流水中丢失。
- 手工新增收入现在同步把年份写入 per-user available-years cache，收入发生在新年份时月份选择器不会遗漏该年份。
- AI 队列页现在提供本地任务输入、显式“处理下一条”入口和重试；coordinator 不再把 `enabled` 强制改为 true，未开启网络时会 fail-closed，避免 UI 入口绕过隐私开关。
- AI 队列支持取消尚未 claim 的 queued task；running task 的网络取消仍需由 AbortSignal owner 接入，当前不会伪造“已取消网络请求”的语义。
- AI queue 现在通过 AbortSignal 取消 running 请求，并在 task marker 已是 cancelled 时避免把取消误写成 failed；代码/单测通过，仍需设备网络回归验证真实 fetch 实现。

### 交互与性能

录入使用单一 `AddEntryScreen` 和 typed `EntryMode`，底部导航保持各 tab mounted；indicator、crossfade、active pill 使用 Reanimated UI thread，并遵守 `ReduceMotion.System`。动画不能掩盖查询竞态、重复挂载或状态丢失。

性能只接受同设备、同 release Hermes/Fabric、同 fixture 的 Zero/Zerox/候选对照。至少 30 次样本并保存原始 JSON；没有报告时不能使用“更快”“提升 X%”等结论。

### 工程与发布

每个大步必须经过：最新代码重评估 → 对抗性审查 → 代码质量审查 → 注释审查 → 定向与全量验证 → 文档更新 → Conventional Commit。CI 保留 `braces` 高危公告为明确发布阻断，不伪造 override 或关闭审计。debug APK 静态检查不能替代设备启动、迁移、签名 AAB 或 iOS 验证。

## 本轮增量审查：AI 子分类解析
