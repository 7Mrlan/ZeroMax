# 隐私说明（候选版本）

- 应用默认关闭 AI 网络能力；手工开启后，用户提供的 endpoint 只允许
  HTTPS 和明确的 host allowlist。
- API key 仅写入 Android Keystore 加密存储；不写入 Redux、WatermelonDB、
  导出文件、诊断日志、错误文本或 JavaScript bundle。iOS Keychain 适配和
  iOS 设备验证仍待 macOS/Xcode 环境完成。
- 本地账单、分类、预算、债务和迁移备份默认留在设备上。用户主动执行
  JSON/CSV 导出或系统分享时，文件才会离开应用沙盒。
- 项目不主动接入分析、广告或崩溃上报服务；第三方依赖和许可证见
  [THIRD_PARTY_LICENSES.json](./THIRD_PARTY_LICENSES.json)。

AI 解析结果必须经过 Zod 校验和本地分类匹配；任务使用稳定幂等键，重复
执行不会新增第二笔相同记录。用户应避免把身份证、银行卡或其他敏感信息
输入第三方 AI endpoint。
